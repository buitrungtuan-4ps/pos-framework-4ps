- **Receipt templates are edited in the console.** Shared settings draws `receipt.templates` as an
  editor: the base template and each sales channel's, up to four lines above and below the receipt
  picked from the translations that have English, and each optional section on or off, with the
  sections a country's law requires shown as always printing. `GET /admin/countries` names each
  country's required sections (ADR-0207).
