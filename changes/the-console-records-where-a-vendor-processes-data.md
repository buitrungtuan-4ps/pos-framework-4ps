- **The Integrations screen records where a vendor processes data.** A connection's editor takes the
  processing country as a two-letter code, and its hint warns, before saving, when that is not the
  cell's home country; the table shows the country and flags one outside the cell's (ADR-0179 C7).
  Nothing is refused. The backup destination's country is recorded with the cell's deploy values
  (C8).
