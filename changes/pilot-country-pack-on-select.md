- **Choosing a store's country fills in its country pack.** On Store settings, the **Country**
  select only recorded the country; the pack's values (cash rounding, quick-cash notes, currency,
  display language, quoting posture, registration label) came only from the separate **Start from
  a country** select, so a Vietnamese store could be published with no 1,000 ₫ rounding and no
  notes. Choosing the country now fills the pack into every field nobody has set, and says what it
  filled and which values the store already had that it kept.
