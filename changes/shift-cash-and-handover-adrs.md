- **ADR-0186, 0187 and 0188, accepted: how a till counts, hands over and reads a shift.** A drawer is
  counted note by note and coin by coin from a list each country pack states and each store can
  change; a counted drawer takes no more cash; a safe drop is its own act. A midday handover is one
  flow with a count by each cashier and a slip; the till reads a shift's X without closing it.
  Tapping a free table opens it at once. The code follows in its own changes.
