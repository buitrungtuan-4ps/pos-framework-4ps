- **HQ can let each store choose its package version, choose for a store, and roll back in one
  click** (ADR-0189). *Packages › Versions and pins* now offers the versions a store may choose from
  and the one it runs until it chooses; with a store in context it shows that store's choice and
  changes it. An earlier version's button reads **Roll back to this** while a later one runs.
