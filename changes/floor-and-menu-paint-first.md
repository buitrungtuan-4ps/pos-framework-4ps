- **Clearing a table, giving one back, opening a bill and marking a dish sold out show at once.** A
  cleared table shows *Free*, a table given back leaves the floor's taken tables, a table whose bill
  is opened shows *Awaiting payment*, and a dish shows sold out (or back) on the tap, before the store
  server answers. A refusal puts each back with its sentence; with no answer the till puts it back
  and reads the floor, the open orders or the menu again, since the store server may have made it,
  and never sends it again.
